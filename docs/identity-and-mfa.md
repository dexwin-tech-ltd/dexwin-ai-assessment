# Identity and MFA

Every Okta-connected app requires MFA. SMS is not an approved factor except as
a temporary 24-hour bypass issued by IT.

If you lose your phone, post in **#it-help**. Backup codes live in the
**1Password vault named "Identity"** — use one code, then enroll a new device
the same day. YubiKeys are available on request from IT.

Passwords must be **at least 14 characters**. Reuse is blocked for
**12 months**. There is no shared admin password and no "break glass" spreadsheet.

Phishing-resistant factors (YubiKey or platform passkey) are required for
anyone with production access.
