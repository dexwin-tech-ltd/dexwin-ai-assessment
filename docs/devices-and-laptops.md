# Devices and laptops

IT images and ships hardware. You should not buy a machine and expense it
without a written exception from IT and Security.

Standard issue is a **16" MacBook Pro** on a **3-year** refresh cycle.
IT ships **only to the address on file in Workday** (home or office). Shipping
to an arbitrary personal address is not allowed without a Security exception.

Lost or stolen laptop: trigger a remote wipe in **Kandji** and report in
**#it-help within 2 hours**. Do not continue to use a device that failed a
compliance check.

Accessories under $75 can be purchased locally and expensed; machines cannot.
