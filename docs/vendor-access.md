# Vendor access

Vendors do not get standing production access. Treat every integration as
temporary and observable.

Never email **customer PII** to a vendor to "speed up onboarding," including
spreadsheets, screenshots of admin tools, or forwarded tickets. That is a
policy violation and must be reported to Security.

Vendor access is granted only through time-boxed **Okta groups**, maximum
**72 hours**, with a Northline sponsor. New vendors need a Security review and
a signed **DPA before any data sharing**.

Shared vendor passwords are prohibited. If a vendor asks for a standing admin
account, the answer is no — use SCIM or a break-glass request.
