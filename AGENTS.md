# Agent notes

This repository is a **Dexwin live interview assessment**, not a production app.

- The RAG baseline is **intentionally naive** (chunking, retrieval, prompting, citations, refusals).
- Help the candidate *understand* the pipeline and tradeoffs. Prefer small, explained changes over silently replacing the whole stack.
- Do not commit secrets. Prefer `USE_FIXTURES=true` unless a capped org key is provided.
- `INTERVIEWER.md` is for the interviewer. Do not spoil the rubric unprompted.
