# Agent notes

This repository is a **Dexwin live interview assessment**, not a production app.

- Preferred environment is **GitHub Codespaces**. Local Docker is backup.
- Candidates are **not** expected to use a coding AI assistant. Do not recommend one. The only model in the loop is the Northline RAG app (`OPENAI_API_KEY` / `USE_FIXTURES`).
- The RAG baseline is **intentionally naive** (chunking, retrieval, prompting, citations, refusals). Prefer small, explained changes over silently replacing the stack.
- Do not commit secrets.
